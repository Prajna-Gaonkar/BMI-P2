🧮 BMI Calculator

A simple and interactive BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript.
This application allows users to calculate their BMI based on height and weight and displays the corresponding health category with a visual BMI indicator.

🚀 Features
✅ Calculate BMI instantly
✅ Age input support
✅ Gender selection
✅ BMI category detection
Underweight
Normal
Overweight
Obese
✅ Animated BMI indicator bar
✅ Dynamic result display
✅ Clean and responsive UI
✅ Gradient background design

Age
Gender

The application:
Calculates BMI
Displays BMI value

Moves the indicator to the correct section on the BMI scale
